# Chengqi Xue — personal site, version 2

Served at https://chengqi-xue.github.io/v2/ . The original site at the repository root is left unchanged.

Differences from the root version:
- Sturdier typography: Source Serif 4 (semibold) for headings and figures, self-hosted with IBM Plex Sans; Chinese web fonts load without blocking the page.
- The HRI30 action-recognition work is presented as a research project in its own group at the end of the research list.

Rebuild: run `python3 build_home.py && python3 build_projects.py` inside `sitegen/` (output path is set at the top of each script).
